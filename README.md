# 🎨 COLOR SWITCH

A fast-paced, fully responsive color matching game built with pure HTML5, CSS3, and Vanilla JavaScript. Test your reaction speed, accuracy, and focus!

## 🎮 Play Now

**👉 [Click here to play Color Switch](https://maliyan04.github.io/color-switch/) 👈**

*(Works perfectly on Android, iOS, tablets, laptops, and desktops!)*

---

## ✨ Features

- **📱 Fully Responsive:** Smooth gameplay on mobile phones, tablets, and desktop monitors.
- **🎯 Core Gameplay:** Match the target color before the timer runs out. Fast, addictive, and easy to learn.
- **🔥 Combo System:** Chain correct answers to build your combo multiplier (up to 5×) and maximize your score.
- **❤️ Lives System:** You have 3 lives. One wrong answer or timeout costs a life. Lose all 3 and it's Game Over.
- **📈 Progressive Difficulty:** The game gets harder as you progress—more colors, faster timers, smaller targets, and tricky decoys.
- **⚙️ Persistent Settings:** Toggle Background Music, Sound Effects, Haptic Feedback, and Difficulty (Normal/Hard). All settings are saved locally.
- **🏆 Best Score Tracking:** Your highest score is saved automatically using `localStorage`.
- **🎵 Lightweight Audio:** Upbeat background music and sound effects generated via the Web Audio API (no heavy audio files to load, works offline).
- **📳 Haptic Feedback:** Subtle vibrations on mobile devices (where supported) for correct, wrong, and combo actions.
- **⌨️ Keyboard Support:** Desktop users can use number keys (1-5) to select colors and Escape to pause/quit.
- **🛡️ Stable & Lightweight:** Built with zero external libraries. No heavy animations, no crashes, and no lag.

---

## 🕹️ How to Play

1. **Match the Target:** A large color swatch will appear at the top of the screen.
2. **Choose Quickly:** Tap or click the matching color from the options below.
3. **Beat the Clock:** A timer bar shows how much time you have left for each round.
4. **Build Combos:** Get consecutive correct answers to increase your score multiplier.
5. **Don't Lose Lives:** A wrong answer or running out of time costs one life. You only have 3 lives!

## 🛠️ Tech Stack

- **HTML5** – Semantic and accessible markup.
- **CSS3** – Responsive design, Flexbox, CSS variables, and lightweight animations.
- **Vanilla JavaScript** – Modular game logic, state management, and Web Audio API.
- **Google Fonts** – Pangolin (with system fallbacks).
